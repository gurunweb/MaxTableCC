# /commit — авто-коммит изменений (если в workdir есть git-репо)

Когда юзер пишет «закоммить», «сохрани изменения», «commit» — запусти git-коммит.

## Алгоритм

1. Проверь, есть ли `.git/` в текущей папке:
   ```bash
   if [ ! -d .git ]; then git init -q; fi
   ```
2. Добавь все изменения:
   ```bash
   git add -A
   ```
3. Если ничего не изменилось — сообщи и выйди.
4. Иначе закоммить с осмысленным сообщением (одна строка, что изменилось):
   ```bash
   git commit -q -m "<message>"
   ```

## Сообщение коммита

Сгенерируй сам по содержимому изменений. Без префикса типа `feat:`/`fix:` — просто опиши действие в Imperative («Добавить X», «Исправить Y», «Удалить Z»). На русском, кратко.

## В ответе

Просто короткое подтверждение: «Закоммитил: <hash> · <message>». Без длинных списков файлов.
