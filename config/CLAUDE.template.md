# Контекст чата

Эта папка — workdir одного чата Claude Code, запущенного из Google Sheets.

- Файлы создавай в `outputs/` (раздаётся снаружи по `$CC_FILES_BASE_URL`).
- Входные файлы (если есть) — в `attachments/`.
- Промежуточный лог скриптов / hook'ов — в `audit.log`.

Текущий ID чата: `$CC_CHAT_ID`. Порт для web-приложений: `$CC_APP_PORT`. Базовый URL статики: `$CC_FILES_BASE_URL`.

При продолжении этой темы — пиши код в эту папку, не вылезай за её пределы.
